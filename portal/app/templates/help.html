Pause a device

  1. Open Devices and find the device by name or address.
  2. Select Manage, then a duration under Pause internet: 15 min, 1 hour, or Until resumed.
  3. Review the action and select Approve with security key.
  4. Wait for the firewall result to show done. The device badge changes to Paused.

To restore access, open Manage → Resume internet and approve that change too. Protected management devices may be refused by the firewall.

Block websites

  1. For one device, open Devices → Manage → Block websites. For a whole subnet, open Networks and select its Block sites menu.
  2. Choose categories such as Ads or Social media, or enter domains such as youtube.com, separated by commas. Enter domains, without https:// or a page path.
  3. Choose a duration and select Block sites, then approve with your security key.
  4. Allow about a minute for the firewall's DNS policy to apply. Reopen the site on the affected device.

Subdomains are included. Cached DNS, an app's own secure DNS or a VPN can affect the result. Existing network-wide DNS policies still apply after you remove an OPNGate policy.

Block an external IP

  1. Open {% if session.is_operator %}Actions{% else %}Actions as an operator{% endif %} and choose Block an IP or CIDR.
  2. Enter the external address from the event you investigated and choose the duration.
  3. Select Prepare for signing, check the address and select Approve with security key.
  4. Wait for done. Actions shows in effect while the block is active.

For a local device, use Pause internet instead. The firewall refuses private/local IP blocks and protected targets.

Remove a block or limit

  • Paused device: Devices → Manage → Resume internet.
  • Website policy: reopen its Block sites menu → Allow all sites again.
  • Speed limit: Devices → Manage → Remove speed limit.
  • IP block: Actions → find the active action → Undo.

Approve the removal with your security key, then check the firewall result. Timed policies expire automatically; Until removed/Until resumed policies need an explicit removal.

What happens after approval?

Pending approval means the request has been prepared. Approved means your key signed it. Fetched means the firewall received it. Done is the reported completion; failed includes the firewall's reason.

The firewall checks for actions about every 15 seconds. Website policies can take about a minute to apply. A waiting badge is not proof the change is active. If delivery is interrupted, check the actual device/firewall state before repeating the request.

Controls require an operator account, a passkey registered for this console address and its public key installed in the firewall trust store. Password/TOTP signs you in; control changes still require a security-key signature. If you moved hostnames, register a new passkey in Account security.

WAF blocking is separate

The WAF automatically inspects requests to the websites behind the edge proxy. In On mode it blocks requests that trigger its policy. Threats shows the evidence. Device pause, website DNS policies and external IP blocks use the gateway controls above.

The portal does not provide an unsigned switch for changing edge WAF rules. WAF tuning belongs to the edge administrator.
